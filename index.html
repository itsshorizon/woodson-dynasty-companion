📚 Commissioner Docs

Internal operating manual — patch deployment + end-of-season rollover.

🛠 Patch Deployment Workflow

  1. Sandbox — Never edit live code. Open the local repository folder and a terminal.
  2. Snippet Handoff — When using Claude Code, never paste the entire app.js file. Provide only the specific function snippets that need upgrading to preserve context windows.
  3. Local QA — Double-click index.html to verify visual changes locally before pushing.
  4. GitHub Push — Run git add ., then git commit -m "patch notes", then git push origin main.
  5. Live Refresh — The GitHub Pages URL will automatically compile and update globally within ~60 seconds.

🔄 End-of-Season Rollover Checklist

  1. Update history.json — Scrape the final season standings and points, then manually append the new year's data block into the static JSON file so the Vault graphs update automatically. (Run node scrape-history.js with the new year added to the YEARS array.)
  2. Bump CONFIG.SEASON — Open app.js and update CONFIG.SEASON (e.g. from 2026 to 2027) to point the live ESPN API at the new season slate.
  3. Reset the Stein database — Open the Google Sheet. Archive the old rows, then clear the rows inside the trades, trade_block, and newsletter tabs to provide a clean slate for the new year.
